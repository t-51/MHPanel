## 📖 معرفی سامانه

**MH Panel** یک سامانه سازمانی، ماژولار و بسیار قدرتمند برای مدیریت همه‌جانبه سرورهای لینوکس (اوبونتو ۲۰.۰۴، ۲۲.۰۴، ۲۴.۰۴ و دبیان ۱۱ و ۱۲) است. 

این پنل با ترکیب یک **محیط کاربری تحت وب فوق‌العاده مدرن** (طراحی شیشه‌ای Glassmorphism، تم تاریک و روشن) و یک **کنسول خط فرمان تعاملی و جامع** (`mhpanel`)، کنترل کاملی برای راه‌اندازی بیش از ۱۱ پروتکل پیشرفته VPN و پروکسی، تانل‌های ضد فیلترینگ دوطرفه (IPv4 و IPv6)، مالتی‌پلکسر پورت ۴۴۳ بر بستر SNI، سیستم اکانتینگ یکپارچه FreeRADIUS و تولید خودکار اسکریپت‌های روتربورد میکروتیک (RouterOS نسخه ۶ و ۷) در اختیار مدیران سرور قرار می‌دهد.

## ⚡ نصب سریع و تک‌خطی (One-Line Installer)

کافیست دستور زیر را با دسترسی کاربری `root` روی سرور اوبونتو یا دبیان خود اجرا نمایید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/t-51/MHPanel/main/install.sh)
```

### روش جایگزین با استفاده از Git Clone:

```bash
git clone https://github.com/t-51/MHPanel.git /www/wwwroot/mhpanel
cd /www/wwwroot/mhpanel
sudo bash install.sh
```

### ۱. 🔀 مالتی‌پلکسر پورت ۴۴۳ (HAProxy SNI Dispatcher)
امکان اجرای همزمان چندین سرویس امن SSL/TLS بر روی یک پورت عمومی واحد (۴۴۳):
- `panel.domain.com` ➔ هدایت به وب پنل مدیریت (پورت ۹۰۹۰)
- `vpn.domain.com` ➔ هدایت به سیسکو AnyConnect / OCServ (پورت ۱۰۴۴۳)
- `sstp.domain.com` ➔ هدایت به ویندوز SSTP (پورت ۴۴۴۳)
- `ssh.domain.com` ➔ هدایت به SSH تحت وب‌سوکت و TLS (پورت ۴۴۴۴)
- `ovpn.domain.com` ➔ هدایت به OpenVPN TCP (پورت ۱۱۹۴)
- **نتیجه:** برای فایروال‌های DPI، تمام سرور دقیقاً مانند یک وب‌سایت تجاری معتبر HTTPS به نظر می‌رسد.

### ۲. 👥 مدیریت یکپارچه کاربران با FreeRADIUS 3
- **یک حساب کاربری، تمام پروتکل‌ها:** کاربر با یک نام کاربری و رمز عبور می‌تواند به OpenVPN، Cisco AnyConnect، L2TP، IKEv2، SSTP، SSH و SOCKS5 متصل شود.
- **کنترل سقف مصرف و انقضا:** تعیین سقف ترافیک به گیگابایت (`Max-Octets`) و تاریخ انقضای دقیق (`Expiration`).
- **محدودیت تعداد کاربر همزمان:** جلوگیری از اتصال بیش از سقف مجاز برای هر کاربر (`Simultaneous-Use`).
- **مدیریت نشست‌های آنلاین:** مشاهده اتصالات فعال و قطع آنی سشن با دستور PoD (Disconnect-Request).

### ۳. 🛡️ جعبه‌ابزار پیشرفته ضد فیلترینگ و دور زدن DPI
- **AmneziaWG (AWG):** پروتکل بهینه‌شده و ضد فیلتر وایرگارد با تزریق پکت‌های ساختگی (`Jc`, `Jmin`, `Jmax`) و تصادفی‌سازی هدر دست‌دهی (`S1`, `S2`, `H1..H4`).
- **پچ اسکرامبل OpenVPN (XOR):** مبهم‌سازی الگوهای هدر اوپن‌وی‌پی‌ان با کلید اختصاصی برای بی‌اثر کردن ردیابی فایروال‌های بازرسی عمیق پکت.
- **شتاب‌دهنده UDPspeeder (FEC):** بازسازی بسته‌های از دست رفته (Packet Loss) روی بستر UDP بدون نیاز به ارسال مجدد برای ثبات پینگ در بازی و تماس آنلاین.
- **لایه ضد کوانتوم Rosenpass:** تبادل کلید متقارن پساکوانتومی برای حفظ امنیت اطلاعات در برابر کامپیوترهای کوانتومی نسل آینده.
- **تونل‌های SlowDNS / DNSTT:** عبور تضمینی از شدیدترین اختلالات و قطعی اینترنت بین‌الملل با ارسال داده در قالب کوئری‌های استاندارد DNS.

### ۴. 🔗 پورتال اشتراک اختصاصی کاربر (`/sub/<token>`)
- لینک ساب اختصاصی و رمزشده برای هر کاربر با QR Code هوشمند.
- دانلود مستقیم فایل `.ovpn`، کانفیگ WireGuard، لینک‌های شادوساکس، AmneziaWG و TUIC.
- **خروجی JSON اختصاصی:** ارائه اندپوینت `/sub/<token>/json` جهت اتصال مستقیم به اپلیکیشن‌های اختصاصی اندروید، iOS، ویندوز و مک.

### ۵. 🌍 پشتیبانی بومی و ۱۰۰٪ از سه زبان
- سوییچ آنی میان زبان‌های **فارسی (🇮🇷)**، **انگلیسی (🇬🇧)** و **روسی (🇷🇺)**.
- تمام متون پنل، راهنماها، مودال‌ها، نمودارها و پیام‌های سیستم بدون افتادگی به زبان‌های فوق ترجمه شده‌اند.

| **WireGuard استاندارد** | UDP (v4 و v6) | تمام سیستم‌عامل‌ها (اپلیکیشن رسمی WireGuard) | بیشترین پهنای باند هسته، اختصاص همزمان IPv4 و IPv6، تنظیم خودکار MTU/MSS Clamping. |
| **سیسکو AnyConnect** | SSL/TLS + DTLS | اپلیکیشن رسمی Cisco AnyConnect، OpenConnect | فوق‌العاده پایدار بر روی تمامی اپراتورهای موبایل؛ امکان اشتراک‌گذاری روی پورت ۴۴۳. |
| **ویندوز SSTP (sstpd)** | HTTPS / پورت ۴۴۳ | به صورت پیش‌فرض در ویندوز ۷، ۱۰ و ۱۱ | **بدون نیاز به نصب برنامه؛** در تنظیمات داخلی ویندوز تعبیه شده و شبیه وب‌گردی عادی HTTPS است. |
| **IKEv2 StrongSwan** | IPSec / UDP 500, 4500 | آیفون، مک، ویندوز، اندروید | **اتصال نیتیو و بدون نرم‌افزار.** پایداری عالی هنگام سوییچ از وای‌فای به دیتای موبایل (MOBIKE). |
| **L2TP / IPsec** | UDP 1701, 500, 4500 | روترهای میکروتیک، اندروید، ویندوز | اتصال مستقیم و سازگاری بالا با انواع روترهای شبکه و لینک‌های Site-to-Site. |
| **OpenVPN دوگانه** | مولتی‌پورت TCP و UDP | اپلیکیشن OpenVPN Connect، Tunnelblick | شنود روی چندین پورت همزمان (۴۴۳، ۱۱۹۴، ۹۴۴۳)، پچ XOR Scramble، شتاب‌دهنده UDPspeeder و رمزنگاری Rosenpass. |
| **تونل SSH و وب‌سوکت** | TCP / WSS / Stunnel | ترمینال، NapsternetV، v2rayNG | اتصال مستقیم SSH + پروکسی وب‌سوکت/TLS برای اتصال از بستر CDN + سرویس BadVPN پورت ۷۳۰۰ برای تماس صوتی و گیمینگ. |
| **TUIC v5** | QUIC (HTTP/3) / UDP | Clash Meta, Sing-box, v2rayNG | هندشیک 0-RTT بدون تاخیر اولیه؛ سازگار با الگوریتم‌های مدرن کنترل ازدحام (BBR, Cubic). |
| **شادوساکس (Rust 2022)**| TCP و UDP | Shadowsocks, Clash, Outline, Sing-box | سایفرهای نسل جدید AEAD (`2022-blake3-chacha20poly1305`, `2022-blake3-aes-256-gcm`). |
| **پروکسی MTProto تلگرام** | Fake-TLS / TCP | اپلیکیشن تلگرام رسمی | تظاهر به سایت‌های معتبر (گوگل، کلودفلر) و ثبت تگ کانال اسپانسر (@MTProxybot). |

## 🌐 مرکز تانل‌های شبکه (سرور ایران ↔ خارج) و میکروتیک

سامانه MH Panel کامل‌ترین پکیج ایجاد تونل‌های ارتباطی پایدار میان سرور ایران و خارج را فراهم آورده است:

| نوع تانل | بستر ارتباطی | مزیت و کاربرد ویژه |
|---|---|---|
| **`IP6GRE`** | بستر Native IPv6 | **محبوب‌ترین و ضد فیلترترین تانل:** ترافیک در قالب GRE روی IPv6 عبور کرده و فایروال‌های ملی قادر به تشخیص آن نیستند. |
| **`IP6TNL` (IPIP6)** | بستر Native IPv6 | کپسوله‌سازی مستقیم IPv4 در IPv6 با کمترین هدر اضافه (فقط ۲۰ بایت) و پینگ عالی. |
| **`SIT` (6in4)** | بستر IPv4 | انتقال پکت‌های IPv6 از بستر شبکه IPv4 با پایداری بالا. |
| **`GRE` & `IPIP`** | بستر IPv4 | تانل‌های مستقیم و پرسرعت لایه ۳ استاندارد لینوکس با شتاب‌دهنده هسته. |
| **`WireGuard P2P`** | بستر UDP (v4/v6) | برقراری تونل همتا به همتا با رمزنگاری مدرن و روتینگ دوطرفه. |
| **`GOST v3`** | چند پروتکله | رله کردن پورت‌ها با متدهای مختلف (TLS، WSS، KCP، Relay، Multi-Hop). |
| **`WSTunnel`** | WebSocket | تونل‌سازی کامل TCP/UDP بر روی وب‌سوکت برای عبور از سخت‌گیرانه‌ترین فایروال‌ها و CDN. |
| **`ReverseTls (RTT)`** | TLS معکوس | آغاز ارتباط از سرور خارج به سمت ایران بدون نیاز به باز کردن پورت ورودی در سرور ایران. |
| **`Chisel & Rathole`** | HTTP/Rust NAT | برقراری تونل معکوس و دور زدن NAT با کمترین مصرف حافظه رم و پردازنده. |
| **`Phantun & UDP2Raw`** | Fake TCP | تبدیل ترافیک UDP به بسته‌های ساختگی TCP SYN/ACK برای مقابله با مسدودی و افت سرعت UDP. |

### 📟 تولید خودکار کانفیگ RouterOS میکروتیک:
برای هر تانلی که ایجاد کنید، پنل به صورت خودکار اسکریپت‌های تست‌شده ترمینال میکروتیک را برای هر دو نسخه **RouterOS v7** و **RouterOS v6** تولید می‌کند:
- ایجاد اینترفیس تانل (`/interface gre`, `/interface ip6gre`, `/interface wireguard`)
- آدرس‌دهی آی‌پی‌های داخلی (`/ip address`, `/ipv6 address`)
- جداول روتینگ (`/ip route`)
- رول‌های فایروال NAT Masquerade و بهینه‌سازی MSS Clamping

## 📡 رادار زنده فیلترینگ و تحلیل کیفیت اتصال اپراتورها

داشبورد MH Panel مجهز به **رادار هوشمند فیلترینگ** است که به صورت مداوم وضعیت پایداری و مسدودی را روی ۵ اپراتور اصلی ایران ارزیابی می‌کند:
- **همراه اول (MCI)**
- **ایرانسل (MTN)**
- **شرکت مخابرات ایران (TCI)**
- **شاتل (Shatel)**
- **رایتل (Rightel)**
- **تشخیص تحلیلی سیستم (System Verdict):** تحلیل پکت‌لاس، تغییرات DNS، ارسال بسته‌های مخرب TCP RST و افت بسته‌های UDP به همراه پیشنهادات فنی بهینه برای انتخاب بهترین پروتکل در شرایط اختلال.

## 🔐 امنیت و استحکام هسته سرور

- **احراز هویت دو مرحله‌ای (2FA / TOTP):** سازگار با Google Authenticator و Microsoft Authenticator.
- **مدیریت خودکار گواهینامه‌های SSL:** دریافت و تمدید خودکار گواهی رسمی Let's Encrypt و تولید گواهی ۱۰ ساله IP SAN به همراه فایل دانلودی Root CA (`.crt`) برای کلاینت‌ها.
- **امنیت کامل سورس در گیت:** تمام کلیدهای خصوصی، دیتابیس کاربران و لاگ‌ها توسط `.gitignore` محافظت شده و به مخزن عمومی راه پیدا نمی‌کنند.
- **مدیریت سرویس‌ها با Systemd:** تمامی پردازه‌ها در واحدهای مجزای Systemd با قابلیت راه‌اندازی مجدد خودکار (Auto-Restart) اجرا می‌شوند.
- **بهینه‌سازی کرنل لینوکس:** فعال‌سازی الگوریتم کنترل ازدحام Google BBR، افزایش سقف فایل‌های باز (`nofile` 65535) و بهینه‌سازی بافرهای رم TCP.
