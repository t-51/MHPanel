۲. تفکیک هوشمند پروتکل‌ها روی پورت اشتراکی (SNI Routing & Multi-Service)

SNI Routing

پروتکل‌هایی که مایلید روی پورت‌های اشتراکی بالا همزمان کار کنند را تیک بزنید و دامنه اختصاصی هر کدام را وارد نمایید. سیستم هوشمند HAProxy بسته به دامنه‌ای که کلاینت درخواست می‌دهد، ترافیک را به پروتکل مناسب هدایت می‌کند.

پروتکل پیش‌فرض برای اتصالات مستقیم با IP (بدون SNI):
کلاینت‌هایی که با آدرس IP مستقیم به پورت ۴۴۳ وصل می‌شوند (سیسکو، SSTP، یا سینگ‌باکس بدون دامنه) به این سرویس هدایت می‌شوند.
وب‌سرور اصلی و پنل مدیریت (Apache / Nginx / MHPanel) Default Fallback
ترافیک مرورگر، صفحات وب و ترافیک بدون SNI (رفتار سایت واقعی برای گمراه‌سازی فیلترینگ)
نوع سرور وب:
سیسکو AnyConnect / OpenConnect (OCServ) Cisco SSL
اتصال کلاینت‌های رسمی سیسکو با پورت مشترک با وب‌سایت
تونل امن SSH بر بستر TLS (Stunnel / SSH)

اوپن‌وی‌پی‌ان (OpenVPN TCP)

اتصال مستقیم کانکشن داخلی ویندوز بدون فیلترینگ با SNI
هسته جامع سینگ‌باکس (Sing-box Core - VLESS / Trojan / VMess) Universal Port 443

۳. فراخوانی یک پروتکل روی چندین پورت به صورت همزمان (UDP Multi-Port Engine)

Kernel REDIRECT

برای پروتکل‌های UDP (مانند وایرگارد و امنزیا) که با SNI کار نمی‌کنند، هسته فایروال سیستم (iptables) ترافیک تمامی پورت‌های ورودی انتخاب شده را مستقیماً به پورت اصلی پروتکل هدایت می‌کند. کلاینت‌ها بدون نیاز به تغییر سرور می‌توانند روی هر یک از این پورت‌ها متصل شوند!

وایرگارد معمولی (WireGuard UDP) پورت اصلی: UDP 904
دریافت ترافیک روی پورت‌های متعدد و هدایت به ۹۰۴
امنزیا وایرگارد ضد فیلترینگ (AmneziaWG Anti-DPI) پورت اصلی: UDP 51820
دریافت ترافیک روی پورت‌های متعدد و هدایت به ۵۱۸۲۰
سیسکو AnyConnect DTLS (UDP OCServ) پورت اصلی: UDP 10443
هدایت ترافیک پورت‌های کمکی UDP به سیسکو DTLS برای افزایش سرعت و کاهش پینگ
اعتبارسنجی خودکار قبل از اعمال
کانفیگ HAProxy و فایروال قبل از ذخیره‌سازی تست شده تا از پایداری کامل سرور اطمینان حاصل شود.
