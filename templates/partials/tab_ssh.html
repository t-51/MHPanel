مرکز راهنما و پی‌لودهای بای‌پس فیلترینگ (Connection & Payloads Hub)

تمامی روش‌های دورزدن فیلترینگ با یک کلیک کپی می‌شوند و آماده استفاده در برنامه‌های HTTP Custom, NapsternetV, NetMod, OpenTunnel, Bitvise هستند.

⚡ اتصال مستقیم و پروکسی ساکس ۵ SOCKS5 Direct

📱 فایل کانفیگ و اتصال کلاینت‌ها (SSH) SSH Config

دانلود فایل کانفیگ اختصاصی SSH (.json) یا دریافت لینک هوشمند اتصال برای برنامه‌های NetMod Syna و NapsternetV.

• NetMod Syna: فایل JSON حاوی پورت ۴۴۳ WS، پورت ۲۲ مستقیم و BadVPN UDPGW.
• NapsternetV (NPV): ایمپورت سریع از کلیپ‌بورد با لمس علامت + (پورت ۴۴۳ و ۲۲).

راهنمای رفع خطای احراز هویت (Authentication Error) و نحوه تنظیم در NapsternetV / NPV / HTTP Custom

دلیل عدم اتصال روی پورت ۴۴۳ و تنظیم دقیق گزینه‌های Host، Port و SNI در کلاینت‌های مختلف

⚠️ تفکیک هوشمند پورت ۴۴۳ و نحوه اتصال SSH

روی پورت ۴۴۳ تفکیک ترافیک به صورت خودکار توسط مالتی‌پلکسر انجام می‌شود. در اتصال مستقیم SSH، کدهای دست‌دهی بلافاصله شناسایی و به پورت ۲۲ هدایت می‌شوند. در صورت اتصال از طریق کلاینت‌های با لایه TLS/SSL، وارد کردن دامنه یا SNI الزامی است.

✅ روش ۱: پورت مستقیم Stunnel / TLS

این پورت‌ها بدون تداخل و مستقیماً توسط سرویس TLS با گواهی معتبر مدیریت می‌شوند:

  • نوع پروتکل: SSH (با فعال‌سازی گزینه SSL / TLS)
  • Host (سرور): test.kigaping.com
  • Port (پورت): 22 یا 443
  • Server Name Indication (SNI): test.kigaping.com
  • نام کاربری و رمز: اکانت ساخته‌شده در پنل
⚡ روش ۲: اتصال مستقیم به پورت ۴۴۳

اتصال مستقیم SSH روی پورت استاندارد ۴۴۳ (بدون نیاز به پورت خاص):

  • Host (سرور): test.kigaping.com
  • Port (پورت): 443
  • تیک SSL/TLS: خاموش (در حالت Direct SSH) یا روشن (با SNI)
🌐 روش ۳: حالت وب‌سوکت (WS / WSS) برای CDN و HTTP Custom

بهترین روش برای عبور از پشت شبکه کلودفلر و مخفی‌سازی کامل:

  • نوع اتصال: SSH + WebSocket
  • پورت: 80 (بدون SSL) یا 443 (با SSL) یا 8088
  • مسیر (Path): /ssh یا /ws
